# Data Analytics Portfolio

This repository contains my hands-on Data Analytics projects developed using Power BI, SQL, Excel, Power Query and DAX.

## Projects

### 1. Sales Operations Analytics Dashboard

**Tools Used:**
- Excel
- Power Query
- SQL
- Power BI
- DAX

**Project Overview:**

This project focuses on analysing sales and operational performance using an end-to-end analytics workflow.

Key activities included:

- Data cleaning and transformation using SQL and Power Query
- KPI development using DAX
- Sales and profit analysis
- Regional performance analysis
- Product performance analysis
- Monthly trend analysis
- SLA status analysis
- Interactive dashboard development

**Key KPIs:**
- Total Sales
- Total Profit
- Total Orders
- Average Sales
- Profit Margin
- Quantity

### 2. Airline Passenger Status Analysis

**Tools Used:**
- Excel

**Project Overview:**
